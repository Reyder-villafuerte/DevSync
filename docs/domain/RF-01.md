# Inconsistencia pendiente en RF-01

RF-01 se denomina **“Autenticar usuario”**, pero parte de su criterio de aceptación y
CP-01 describen el registro de un productor.

En la capa Domain de esta etapa, `AutenticarUsuario` implementa autenticación porque ese
es el nombre funcional de RF-01. Los criterios relacionados con el registro de productores
no se incorporaron silenciosamente a este caso de uso y deben aclararse antes de una etapa
posterior.
