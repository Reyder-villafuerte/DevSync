# Contexto de dominio

Archivos de dominio no mapeables al framework ni al estado de sesión.

## Qué va aquí

- Contexto de negocio (reglas del dominio, glosarios, restricciones del cliente)
- Changelogs de contenido (cambios en datos, catálogos, textos de la app)
- Datos de referencia (precios base, tablas de conversión, configuración de producción)

## Qué NO va aquí

| Tipo | Ruta correcta |
|---|---|
| Estado de sesión activa | `overview/session.md` |
| Tareas pendientes / en progreso | `overview/work.md` |
| Progreso de features | `overview/trackers/progress.md` |
| Sesiones archivadas | `overview/history/` |
| Mejoras al core | `overview/learning.md` |
| Flujos de dominio | `overview/workflows/` |
